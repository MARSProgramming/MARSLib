Automated Log Uploader

Manually retrieving USB drives from the RoboRIO after every practice match is tedious and prone to human error. MARSLib introduces the LogUploader, an asynchronous daemon thread that quietly runs in disabledPeriodic(). If it detects a tethered internet connection, it automatically pushes all new AdvantageKit .wpilog files directly to your team's GitHub repository as zip artifacts!

1. Creating a Dedicated Log Repository

Do not upload logs directly into your main robot code repository! Telemetry logs are massive binary files and will quickly bloat your Git history beyond GitHub's repository limits.

  1. Go to your team's GitHub organization.
  2. Create a brand new, empty repository solely for telemetry (e.g. Team2614-Logs).

2. Modifying the MARSLib Configuration

To point the uploader away from our default MARS repository and toward your team's new repository, you must modify the static configuration fields inside `LogUploader.java`.

// Inside src/main/java/com/marslib/util/LogUploader.java

public final class LogUploader {
  // Configuration
  private static final String GITHUB_OWNER = "YourTeamOrganization"; // e.g. "MARSProgramming"
  private static final String GITHUB_REPO = "Your-Log-Repo";         // e.g. "Team2614-Logs"
  private static final int COOLDOWN_SECONDS = 10;
  // ...
}

3. Generating a Personal Access Token (PAT)

The RoboRIO needs permission to upload directly to your team's GitHub organization.

  1. Log into GitHub with an account that has Write access to your log repository.
  2. Navigate to: Settings → Developer Settings → Personal Access Tokens (Fine-grained).
  3. Generate a new token restricted only to the log repository, granting it Read & Write access to Contents.
  4. Copy the exact token string (it will start with github_pat_).

Robot Security

Never hardcode your PAT into Java! If you push your robot code, the world will have access to your repository. The LogUploader explicitly reads the token from a local text file.

4. Deploying the PAT to the RoboRIO

You must place your token inside the RoboRIO's deploy directory so the runtime can read it. Create a new file locally in your project:

src/main/deploy/github_pat.txt

Paste the github_pat_... string directly into this file and save it (no newlines). The next time you deploy your robot code via Gradle, the deploy folder is automatically synced to /home/lvuser/deploy/ on the RoboRIO. The LogUploader daemon will find it there automatically!

5. Execution

The system is completely automatic. It checks the DriverStation.isFMSAttached() flag to ensure it never uploads during real matches (which is illegal and causes bandwidth violations). During practice or lab sessions, whenever the robot is disabled and tethered to a laptop with internet sharing enabled, it will scan the USB drive and quietly push the logs into your new repository's Releases tab!
