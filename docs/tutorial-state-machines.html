State Machine Logic

Coordinating multiple mechanisms (like an intake, a pivot, and a shooter) is hard. If you use simple if-statements, you'll eventually end up with "spaghetti code" where the robot crashes into itself. MARSLib uses MARSStateMachine to manage these transitions safely.

1. Defining Your States

Start by creating an enum that represents every possible state of your mechanism.

public enum SuperstructureState {
  IDLE,
  INTAKING,
  LOADED,
  SHOOTING,
  UNJAMMING
}

2. The Transition Table

In your Subsystem's constructor, you define which transitions are legal. This prevents the robot from trying to shoot if it hasn't finished intaking!

stateMachine = new MARSStateMachine<>("Superstructure", SuperstructureState.class, SuperstructureState.IDLE);

// Setup the table
stateMachine.addTransition(IDLE, INTAKING);
stateMachine.addTransition(INTAKING, LOADED);
stateMachine.addBidirectional(LOADED, SHOOTING);
stateMachine.addWildcardTo(IDLE); // Can always go back to IDLE in emergency

3. Entry & Exit Actions

Often, you want something to happen exactly once when a state changes. For example, when entering INTAKING, you want to deploy the pivot.

stateMachine.setEntryAction(INTAKING, () -> {
  pivot.setGoal(IntakeConstants.DEPLOY_POS);
  intakeWheels.run(1.0);
});

stateMachine.setExitAction(INTAKING, () -> {
  pivot.setGoal(IntakeConstants.STOW_POS);
});

4. Live Mermaid Visualization

One of the most powerful features of MARSStateMachine is that it automatically generates a **Mermaid.js flowchart**. This graph is sent over telemetry and can be viewed live in **AdvantageScope**.

Visualization in AdvantageScope

Open the "Mermaid" tab in AdvantageScope and drag the Superstructure/StateMachine/MermaidGraph field into it. You will see a live diagram where the current state is highlighted in glowing green!

Student Pro-Tip

Use stateMachine.getTicksInCurrentState() for timeout-based transitions. For example, if you've been in INTAKING for 150 ticks (3 seconds) without seeing a game piece, automatically return to IDLE.
