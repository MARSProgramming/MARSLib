Agentic Skill Architecture

MARSLib is one of the first FRC frameworks to be co-developed with Agentic AI. To ensure that AI contributions remain deterministic, allocation-free, and compliant with our elite performance metrics, we utilize a strictly governed Agentic Skill Architecture stored directly within the repository.

What is an AI Skill?

A "skill" is a set of hardcoded rules, architectural boundaries, and syntax requirements that an AI assistant must read before modifying specific framework subsystems. This prevents AI agents from injecting garbage-heavy code (like frequent `new` object allocations) into the 20ms hot path.

1. The `.agents/skills` Directory

Every major package in MARSLib has a corresponding skill folder. When an AI agent attempts to modify a file in the swerve package, it is required to read marslib-swerve/SKILL.md first. These documents enforce:

  • Zero-Allocation Rules: Banning local object instantiation in logic loops.
  • Telemetry Standardization: Forcing all logging through AdvantageKit rather than NetworkTables.
  • Design Systems: Enforcing 2026 Game Terminology across web documentation.

2. Available AI Skills

The following skills are available to the AI workforce when assisting our developers:

SYSTEM CORE

marslib-core-standards

Enforces strict elite coding standards including 'Never Nester', explicit unit nomenclature, and avoiding Hungarian notation.

SYSTEM CORE

marslib-ci

Helps understand build automations, Gradle tasks, Spotless linting formatting, and deployment workflows.

SYSTEM CORE

marslib-testing

Enforces testing architecture using JUnit 5 combined with dyn4j to ensure high-fidelity physical testing across all subsystems.

SYSTEM CORE

marslib-skill-authoring

Self-referential framework rules for generating new SKILL.md constraints when introducing major features.

HARDWARE & PHYSICS

marslib-swerve

Configuration directives for the SwerveDrive subsystem, focusing on high-frequency odometry and alignment performance.

HARDWARE & PHYSICS

marslib-mechanisms

Architects new subsystem mechanisms (elevators, arms) enforcing strict AdvantageKit IO abstractions.

HARDWARE & PHYSICS

marslib-power

Regulates electrical hardware limits, CAN bandwidth optimization, and dynamic brownout protection logic.

HARDWARE & PHYSICS

marslib-simulation

Manages the dyn4j 2D physics engine, rigid body colliders, and interactive AdvantageScope field representations.

CONTROL & MODELING

marslib-control-theory

Architects PID loops, Feedforwards, cascaded controllers, and kinematics models across mechanism layers.

CONTROL & MODELING

marslib-math

Processes continuous mathematical logic, regression, interpolation maps, and vector transformations.

CONTROL & MODELING

marslib-shotsetup

Configures the Shoot-On-The-Move (SOTM) iterative solvers, shot maps, and time-of-flight convergence parameters.

LOGIC & ORCHESTRATION

marslib-statemachine

Builds validated finite state machines for subsystem coordination requiring transition verification and telemetry mapping.

LOGIC & ORCHESTRATION

marslib-superstructure

Coordinates heavy cross-subsystem orchestration across intakes, feeders, and shooters ensuring collision-free handling.

LOGIC & ORCHESTRATION

marslib-autonomous

Integrates PathPlanner macros, AutoBuilder paths, and named scoring commands.

OPERATOR INTERFACE

marslib-operator

Formulates Command Controller layouts, rumble haptics, and pilot/copilot UI dashboard experiences.

DIAGNOSTICS & TELEMETRY

marslib-telemetry

Mandates deterministic replay tracking using Replay Watch and automated cloud backup via the LogUploader.

DIAGNOSTICS & TELEMETRY

marslib-diagnostics

Enforces the SystemTestable hardware sweep pattern, CAN dropout handling, and MARSFaultManager usage.

VISION & INTEGRATION

marslib-vision

Guidance on MegaTag 2.0 integration, AprilTag 3D Odometry injection, and coordinate framework mapping.

WEB & EDUCATION

marslib-documentation

Governs the MARSLib web hub. Enforces Orbitron/Ubuntu fonts, dark-mode CSS variables, and the 2026 REBUILT game terminology.

WEB & EDUCATION

marslib-javadoc

Enforces championship-tier API documentation standards. Mandates unit descriptions and bans empty stub comments.

Our AI agents are also equipped with the marslib-elite-mining skill. This allows them to systematically ingest and translate advanced mathematical concepts directly from world champion codebase architectures into MARSLib-compliant syntax.
