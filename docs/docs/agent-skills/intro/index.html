MARSLib AI Skills

MARSLib is the world's first FRC software framework specifically architected for Agentic Co-Development.

Embedded within the framework is a suite of 26 curated .agent markdown skill files. Instead of manually scaffolding standard subsystems or memorizing WPILib physics nuances, you can interface these skills directly into your IDE. AI agents (like Claude Code, Cursor, or Antigravity) will read these strict rulesets to autonomously write, audit, and refactor code conforming perfectly to MARSLib's championship-grade constraints.

Why Use Agent Skills?​

Every framework has unspoken rules. MARSLib's primary rule is the Zero-Allocation Hot Path. By providing your agent with explicit .agent files natively, it understands the overarching philosophy of the 20ms physics tick without needing human correction.

  • Automates the Boilerplate: Inject properly mapped LinearMechanismIO interfaces across Simulation and Real Hardware hardware with zero human typing.
  • Enforces Determinism: Agents are strictly instructed to avoid new keywords in continuous execution blocks.
  • Auditing Automation: Run marslib-audit to execute a comprehensive code review checking against world-champion FRC patterns.

Featured Capabilities​

While there are over 20+ specialized skills in the .agents/skills repository, here are the most critical tools to elevate your workflow:

⛏️ Elite Mining

marslib-elite-mining

Instructs the agent how to port elite code from top-tier repositories (1690, 254, 6328) into MARSLib's exact structure.

🛡️ Zero-Allocation Audit

marslib-audit

Performs a championship-grade codebase audit prioritizing loop determinism, garbage collection pressure, and concurrency.

🦾 Mechanism Scaffolder

marslib-mechanisms

Generates Subsystems, generic IO interfaces, IOSim stubs, and IOReal adapters aligned perfectly to AdvantageKit.

🏎️ Swerve Architect

marslib-swerve

Expert-level agent instructions for adding odometry sources, tweaking Phoenix 6 kinematics, and setting up AutoBuilder.
