Zero-Allocation Engineering

The single greatest threat to determinism in a Java-based FRC robot is the JVM's Garbage Collector (GC). Every time you use the new keyword to instantiate an object inside your 50Hz or 250Hz loops, memory is allocated on the heap. Eventually, the JVM pauses the entire robot to clean it up. This causes a sudden, violent 20-30ms spike where your PID loops stall and your odometry misses critical sensor updates.

1. The 'Ephemeral Struct' Pattern

To eliminate these GC spikes, MARSLib enforces a strict zero-allocation architecture across hot loops. We achieve this using pre-allocated Mutable Proxy References, governed strictly by our Agentic AI skill parameters.

// BAD: Allocates 250 objects per second inside the Odometry Thread!
public void periodic() {
    Pose2d currentPose = new Pose2d(x, y, new Rotation2d(theta));
    updatePose(currentPose);
}

// GOOD: Pre-allocated Ephemeral Structs that are mutated in place
private final Pose2d mutablePose = new Pose2d();
private final Rotation2d mutableRotation = new Rotation2d();

public void periodic() {
    // No 'new' keyword. Pure mathematical mutation.
    mutableRotation.setRadians(theta);
    mutablePose.set(x, y, mutableRotation);
    updatePose(mutablePose);
}

2. The Pointer Danger

When you pass a mutable proxy reference into another class (like a trajectory follower), you are passing the memory pointer. When the 20ms loop executes again next tick, it will overwrite the internal values of that exact same object!

The Clone Rule

If a downstream class requires a persistent snapshot or history of data across multiple ticks (like calculating derivative error over time), it must explicitly clone the proxy object. Our rule is: "Assume any struct reference passed into a function is mathematically poisoned the moment the function returns."

3. Static Array Caching

In Swerve Kinematics, we frequently convert ChassisSpeeds into arrays of SwerveModuleState[]. WPILib's native toSwerveModuleStates() allocates a new array every call. MARSLib overrides this with a static pre-allocated array cache, mutating the array elements in place to save thousands of heap allocations a minute.
