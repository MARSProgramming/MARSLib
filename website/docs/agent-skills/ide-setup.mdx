MARSLib's `.agent` markdown framework is naturally agnostic, meaning the skills can integrate into whatever AI workflow your programming team prefers. 

By mapping the `.agents/skills` directory to your local assistant, you provide the Language Model with **RAG (Retrieval-Augmented Generation)** context specifically tailored for FRC and MARSLib.

Below are the recommended setups for the most popular FRC software development workflows.

---

## 1. Antigravity & Z.ai

Antigravity operates natively as an agentic IDE plugin, making it exceptionally powerful for MARSLib integration since it supports multi-file codebase operations out of the box.

1. Install the appropriate IDE extension (e.g. Z.ai).
2. Inside your `MARSLib` workspace root, Antigravity will automatically detect the `.agents/skills` folder.
3. When issuing a command, simply mention the skill:
   > *"I need an elevator subsystem. Use the `marslib-mechanisms` skill to write the IO Layer."*

The system will automatically `view_file` on `SKILL.md` inside that directory and follow the strict AdvantageKit and Loop Determinism rules without hallucinating standard WPILib templates.

---

## 2. Cursor

Cursor features a native **Rules for AI** system (`.cursorrules`) that can map external markdown files as universal context.

1. Open your MARSLib project in Cursor.
2. Press `Ctrl + L` (or `Cmd + L`) to open the Cursor Chat.
3. Use the `@Files` or `@Folders` targeting system.
4. Type `@.agents/skills/marslib-swerve` into the context window before asking a kinematics question.

**Pro-Tip:** You can compile multiple skills into a master `.cursorrules` file to permanently enforce MARS programming conventions on every chat window automatically.

---

## 3. Claude Code (CLI)

Anthropic's `claude-code` CLI is excellent for headless CI/CD operations or rapid codebase refactoring via the terminal.

1. Navigate to the root directory: `cd MARSLib`
2. Launch the CLI: `claude`
3. Load the skill directly into the context window using the file reference:
   > `/add .agents/skills/marslib-audit/SKILL.md`
4. Prompt the agent: *"Execute the audit skill against my current SwerveDrive subsystem and fix any hot-path allocations."*

---

## 4. GitHub Copilot 

GitHub Copilot Chat inside VS Code now supports workspace mapping and file referencing.

1. Open the **Copilot Chat Sidebar**.
2. Start your prompt with `#file` and point it at the relevant skill:
   > `#file .agents/skills/marslib-control-theory/SKILL.md Generate a feedforward voltage calculation for my Arm using this specific MARSLib convention.`
3. Ensure you have the `github.copilot.advanced` settings enabled for local workspace parsing if you want Copilot to index the entire skills array automatically.
