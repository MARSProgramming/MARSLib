MARSLib is built to strictly interface with the industry-standard components in the FIRST Robotics Competition ecosystem. We extend our deepest gratitude to these framework providers and recommend reading their core documentation:

## Fundamental Upstream Docs
- [WPILib Documentation](https://docs.wpilib.org/en/2025/): The official FRC programming foundation.
- [AdvantageKit Docs](https://docs.advantagekit.org/): Log replay architecture integration.
- [AdvantageScope](https://docs.advantagescope.org/): Telemetry and 3D field layout visualization.

## Hardware Guides
- [CTRE Phoenix 6](https://v6.docs.ctr-electronics.com/): Motion control / CAN FD for TalonFX & Pigeon2.
- [REV Robotics (REVLib)](https://docs.revrobotics.com/brushless/revlib): SPARK MAX/Flex motor controller guides.

## Vision & Autonomous
- [Limelight Vision](https://docs.limelightvision.io/): MegaTag AprilTag tracking.
- [PhotonVision](https://docs.photonvision.org/): Open-source vision solutions.
- [PathPlanner](https://pathplanner.dev/home.html): Autonomous path trajectory GUI.

## Simulation Physics Engine
- [Dyn4j Physics](https://dyn4j.org/): The 2D physics engine empowering MARSLib's full-field rigid-body simulation backend.

## Acknowledgments
MARSLib stands upon the shoulders of giants. We extend our deepest gratitude to the **MapleSim** project for their groundbreaking simulation patterns, and to the incredible open-source maintainers, corporate sponsors, and the FIRST community for making modern FRC software possible.
