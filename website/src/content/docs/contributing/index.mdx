# Contributing to MARSLib

Thank you for your interest in contributing to MARSLib! This framework is used by FRC teams worldwide to build championship-tier robots, and your contributions make a real difference.

## Why Contribute?

- 🤖 **Help FRC Teams** - Your code helps teams compete at the highest level
- 🧠 **Learn Robotics** - Work with advanced control theory and simulation
- 🏆 **Build Portfolio** - Gain experience with production-grade software
- 👥 **Join Community** - Collaborate with passionate developers and students

## Quick Start

1. **Set up your development environment** (5 minutes)
2. **Find a good first issue** to work on
3. **Make your changes** following our coding standards
4. **Test thoroughly** using our simulation framework
5. **Submit a pull request** with description

## Ways to Contribute

### 🐛 Bug Fixes
Find and fix bugs in the framework. Check out our [open issues](https://github.com/MARSProgramming/MARSLib/issues) for reported bugs.

### ✨ New Features
Add new capabilities to the framework. Start with a [discussion](https://github.com/MARSProgramming/MARSLib/discussions) to align on approach.

### 📚 Documentation
Improve documentation, add examples, or create tutorials. Great for first-time contributors!

### 🧪 Testing
Add test coverage or improve existing tests. We maintain 80% coverage for quality.

### 🎨 Examples
Create example projects or code snippets showing how to use MARSLib features.

## Community Guidelines

### 🤝 Be Respectful
Treat all contributors with respect and kindness. We're all learning together.

### 💬 Ask Questions
Don't hesitate to ask for help. Use GitHub Discussions for questions.

### 📖 Follow Patterns
Study existing code before making changes. Consistency is key to maintainability.

### 🧪 Test Thoroughly
Our Digital Twin testing approach ensures quality. Always test your changes.

### 📝 Document Changes
Update documentation alongside code changes. Keep docs in sync with code.

## Recognition

Contributors are recognized in:
- GitHub Contributors list
- Release notes for significant contributions
- Team meetings for major features
