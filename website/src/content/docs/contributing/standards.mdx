<SplashContainer>
  <RuleSection num="01" title="Championship-Grade Execution">
    MARSLib is not built to participate; it is built to compete on the Einstein field. Every line of code, architectural decision, and kinematic algorithm in this framework is engineered to eliminate overhead, reduce latency, and maximize the hardware performance ceilings of FRC robots. We do not compromise on execution speed.
  </RuleSection>

  <RuleSection num="02" title="Zero-Allocation Performance">
    To compete at the highest level, the JVM Garbage Collector cannot be allowed to interrupt a control loop. We enforce a strict **Zero-Allocation Architecture** in all active teleop and autonomous hot-paths. By utilizing statically-allocated Ephemeral Structs and avoiding the `new` keyword during matches, MARSLib ensures deterministic, sub-250µs execution loops.
  </RuleSection>

  <RuleSection num="03" title="AI Co-Development & Autonomy">
    MARSLib is the first FRC framework expressly co-developed with Artificial Intelligence. To instruct Claude Code or Z.ai agents efficiently, we utilize explicit structuration and agentic block comments. Code that is actively governed by an AI skill carries the `@AGENT_ENFORCED` JavaDoc tag, establishing a symbiotic relationship between human engineers and autonomous agents, allowing for rapid iteration and elite code mining.
  </RuleSection>

  <RuleSection num="04" title="AI-Integrated Mentorship">
    Beyond raw code generation, MARSLib employs AI as an active educational mentor. The framework features a built-in AI Tutor skill designed specifically to override standard efficiency directives. Instead of just producing code, the AI acts as a Socratic mentor—patiently explaining the architecture, asking leading questions, and breaking down complex physics concepts. This guarantees that students truly learn engineering principles rather than just copying implementations.
  </RuleSection>

  <RuleSection num="05" title="Inclusive by Design (WCAG 2.1 AA)">
    Engineering excellence is meaningless if it cannot be accessed by every student and developer. MARSLib fundamentally requires **WCAG 2.1 AA** compliance for all documentation, dashboards, and associated frontend repositories. We deploy autonomous Pa11y pipelines to enforce strict mechanical standards for screen readers, keyboard navigability, and high-contrast accessibility.
    
    Read our full [Accessibility Commitment](/accessibility) to see how we guarantee open access to robotics resources.
  </RuleSection>
</SplashContainer>
