# Competition Preparation Guide

Prepare your robot and team for competition success! This guide covers everything from pre-season preparation to match day execution.

## Pre-Season Preparation (1-2 weeks before event)

### Robot Preparation Checklist

**Hardware Inspection**:
- [ ] All mechanisms secure and safe
- [ ] Wiring neat and protected
- [ ] Bumpers installed and secure
- [ ] Robot weighs under 125 lbs
- [ ] Size within starting configuration
- [ ] Main breaker easily accessible
- [ ] All sensors connected and working

**Software Preparation**:
- [ ] All code committed to Git
- [ ] Tagged release for competition
- [ ] Tested in simulation thoroughly
- [ ] Tested on real robot (if available)
- [ ] Autonomous modes selected and tested
- [ ] Operator interface tested
- [ ] Backup code ready to deploy
- [ ] Emergency access code ready

**Documentation**:
- [ ] Robot inspection checklist complete
- [ ] Quick reference guides printed
- [ ] Troubleshooting guides reviewed
- [ ] Network configuration documented
- [ ] Autonomous routines documented
- [ ] Contact info for team members ready

## At Competition: Setup Day

### Robot Inspection Preparation

**Before Inspection**:
1. **Review Inspection Checklist**:
   - Robot size (&lt; 33" x 28" x 60")
   - Weight (&lt; 125 lbs)
   - Bumpers (8" covered, 5" high)
   - Main breaker accessible
   - All wiring protected
   - No sharp edges

2. **Prepare Documentation**:
   - Bill of Materials (BOM) ready
   - Wiring diagrams available
   - System block diagram ready
   - Safety features documented

3. **Physical Inspection Prep**:
   - Clean robot
   - Secure all loose wires
   - Label all motors/sensors
   - Check main breaker accessibility
   - Verify bumper attachment

**During Inspection**:
- **Be polite and cooperative**
- **Answer questions clearly**
- **Know your robot** (students should lead)
- **Have tools ready** for minor fixes
- **Ask questions** if you don't understand

### Field Testing

**Before Matches**:
- [ ] Connect to field network
- [ ] Test driver station connection
- [ ] Verify joysticks work
- [ ] Test autonomous mode
- [ ] Test teleop driving
- [ ] Verify camera (if used)
- [ ] Check all systems working

## Match Day Routine

### Before Each Match

**30 Minutes Before**:
- [ ] Confirm queue position
- [ ] Verify robot in correct configuration
- [ ] Check battery charge
- [ ] Test all subsystems briefly
- [ ] Confirm autonomous mode selected
- [ ] Verify driver station connection

**10 Minutes Before**:
- [ ] Move robot to queue
- [ ] Final systems check
- [ ] Battery at full charge
- [ ] Connect to field network
- [ ] Verify connection quality
- [ ] Drivers get in position
- [ ] Operators ready

**2 Minutes Before**:
- [ ] Robot on field
- [ ] Verify autonomous selected
- [ ] Check DS lights are green
- [ ] Confirm team ready with FMS
- [ ] Final brief with drive team

### During Match

**Autonomous Period**:
- Watch for issues
- Note any problems for post-match
- Don't interfere with robot
- Be ready for quick fixes if needed

**Teleop Period**:
- Monitor robot performance
- Watch for any problems
- Note any unusual behavior
- Stay ready to troubleshoot

**After Match**:
- [ ] Retrieve robot safely
- [ ] Turn off robot
- [ ] Move to pit area
- [ ] Connect to practice network
- [ ] Check robot for damage
- [ ] Review match performance

## Crisis Management

### Common Competition Crises

**Crisis 1: Robot Won't Connect**
**Symptoms**: Communications red, can't control robot

**Quick Fix** (30 seconds):
1. Check radio powered on
2. Check ethernet connections
3. Power cycle robot
4. Reconnect DS to network

**If Still Not Working**:
- Call FTA (Field Technical Assistant)
- Have backup RoboRIO ready
- Use backup robot code

**Crisis 2: Code Crashed**
**Symptoms**: Robot code red, robot not responding

**Quick Fix** (2 minutes):
1. Check RioLog for error
2. Quick fix if obvious
3. Deploy backup code
4. Test in practice area

**Prevention**:
- Have backup code ready
- Test all code thoroughly
- Have simple backup mode ready

**Crisis 3: Mechanism Failed**
**Symptoms**: Something broke or stopped working

**Quick Fix**:
1. Identify what broke
2. Check for obvious damage
3. Quick repair if possible
4. Disable function if needed
5. Adjust autonomous mode

**Prevention**:
- Test mechanisms under load
- Have spare parts ready
- Design for redundancy

**Crisis 4: Battery Died**
**Symptoms**: Robot brownout, stopped working

**Quick Fix**:
1. Swap battery
2. Check for high current draw
3. Verify battery charger working
4. Monitor battery voltage next match

**Prevention**:
- Monitor battery voltage
- Have charged batteries ready
- Check for short circuits

## Performance Monitoring

### During Competition

**Monitor These Metrics**:
- Loop times (keep &lt;10ms)
- Battery voltage
- CAN bus utilization
- NetworkTables traffic
- Memory usage

**Dashboard Setup**:
```java
// Add to competition dashboard
SmartDashboard.putNumber("LoopTime_ms", loopTime);
SmartDashboard.putNumber("Battery_Voltage", RobotController.getBatteryVoltage());
SmartDashboard.putNumber("CAN_Utilization", canBus.getBusUtilization());
SmartDashboard.putBoolean("VisionTarget", vision.hasTarget());
```

### Identify Issues Early

**Warning Signs**:
- Loop times increasing
- Battery voltage dropping
- CAN utilization >80%
- Connection drops
- Unusual behavior

**Take Action**:
- Note pattern of issues
- Plan fixes between matches
- Monitor closely next match
- Have backup plan ready
