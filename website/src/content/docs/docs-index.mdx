## 🪐 Our Foundation: _FIRST_® Core Values

MARSLib is more than just code; it is a platform for **Discovery**, **Innovation**, and **Impact**. Every architectural decision is rooted in the _FIRST_® Core Values. 

- **Discovery & Innovation**: We explore the limits of FRC physics and zero-allocation logic to solve complex problems with creative persistence.
- **Inclusion & Teamwork**: Our documentation and tools are designed to be accessible to everyone, fostering a collaborative environment where we work together to build championship-grade systems.
- **Impact & Fun**: We apply our skills to improve the team's field performance and celebrate our technical breakthroughs together!

## 📚 Learning Paths

### Beginner (Weeks 1-2)
**Perfect for**: New to MARSLib or robot programming

**What you'll learn**:
- Set up development environment
- Create first robot program
- Make robot move with controllers
- Test in simulation

**Start here**: [Beginner Learning Path](/getting-started/01-setup-and-infrastructure/)
**Time**: 10-15 hours total

### Intermediate (Weeks 3-4)
**Perfect for**: Understand basics, want advanced features

**What you'll learn**:
- Vision systems and cameras
- Advanced autonomous routines
- Path optimization and tuning
- Competition preparation

**Prerequisites**: Complete beginner path

### Advanced (Weeks 5-6)
**Perfect for**: Ready for championship-level features

**What you'll learn**:
- State machines and advanced patterns
- Multi-robot coordination
- Computer vision algorithms
- Performance optimization

**Prerequisites**: Complete intermediate path
