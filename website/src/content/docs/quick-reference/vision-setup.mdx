# Vision Setup Quick Reference

Get your robot seeing the field! This guide helps you set up vision cameras quickly.

## Choose Your Vision System

**Limelight** (Easiest):
- ✅ Built-in web interface
- ✅ Works out of the box
- ✅ Great for beginners
- ❌ Costs money ($400+)

**PhotonVision** (Free):
- ✅ Completely free
- ✅ Open source
- ✅ Customizable
- ❌ Requires setup

## Limelight Setup (10 minutes)

### Step 1: Physical Installation

**Mount the camera**:
1. Attach Limelight to robot using provided brackets
2. Aim camera slightly upward (10-15 degrees)
3. Secure all bolts tightly
4. Connect power to PDp
5. Connect Ethernet to switch

**Tip**: Test mounting location first with tape!

### Step 2: Network Configuration

**Connect to Limelight**:
1. Connect computer to Limelight's WiFi
   - Network: `limelight-<team>`
   - Password: `12345678`

2. Open web browser
3. Go to: `http://10.0.0.1` or `http://limelight.local`

3. Set team number:
   - Settings → Team Number → Enter your FRC team number
   - Click "Save"

### Step 3: AprilTag Detection

**Enable AprilTags**:
1. Go to "Pipeline" tab
2. Select "AprilTag" from dropdown
3. Set these settings:
   ```
   Exposure: 25
   Brightness: 50
   Gain: 50
   ```
4. Click "Apply"

**Test detection**:
- Point camera at AprilTag
- Check "Targets" section in web interface
- You should see green boxes around tags

### Step 4: Robot Code Integration

**Add Limelight to robot**:

```java
// In subsystem constructor
private final LimeLight limelight = new LimeLight();

public VisionSubsystem() {
    // Limelight automatically connects
}

// In periodic method
public void periodic() {
    // Check if target visible
    boolean hasTarget = limelight.getIsTargetFound();
    
    // Get target data
    double tx = limelight.getTx();  // Horizontal angle
    double ty = limelight.getTy();  // Vertical angle
    double ta = limelight.getTa();  // Target area
    
    // Send to dashboard
    SmartDashboard.putBoolean("HasTarget", hasTarget);
    SmartDashboard.putNumber("TargetX", tx);
    SmartDashboard.putNumber("TargetY", ty);
}
```

### Step 5: Vision Aiming Command

**Auto-aim command**:

```java
public class VisionAimCommand extends Command {
    private final Drivetrain drivetrain;
    private final VisionSubsystem vision;
    
    public VisionAimCommand(Drivetrain drivetrain, VisionSubsystem vision) {
        this.drivetrain = drivetrain;
        this.vision = vision;
        addRequirements(drivetrain);
    }
    
    @Override
    public void execute() {
        if (vision.hasTarget()) {
            double tx = vision.getTargetAngleX();
            
            // Turn towards target
            double turnSpeed = tx * 0.1;  // Proportional control
            drivetrain.drive(0, 0, turnSpeed);
        }
    }
    
    @Override
    public boolean isFinished() {
        // Aim within 1 degree
        return Math.abs(vision.getTargetAngleX()) < 1.0;
    }
}
```

**Use the command**:
```java
// In RobotContainer
driverButton_x.whileTrue(new VisionAimCommand(drivetrain, vision));
```

## PhotonVision Setup (15 minutes)

### Step 1: Install PhotonVision

**Download and flash**:
1. Go to: [photonvision.org](https://photonvision.org)
2. Download Raspberry Pi image
3. Flash to SD card using [BalenaEtcher](https://etcher.balena.io)
4. Insert SD card into Raspberry Pi
5. Connect camera to Raspberry Pi
6. Power on Raspberry Pi

### Step 2: Connect to PhotonVision

**First time setup**:
1. Connect computer to PhotonVision WiFi
   - Network: `PhotonVision`
   - Password: `12345678`

2. Open browser: `http://10.0.0.1`

3. Configure settings:
   - Camera: Choose your camera type
   - Team Number: Enter your team number
   - Save and reboot

### Step 3: AprilTag Setup

**Create AprilTag pipeline**:
1. Go to "Vision Pipelines" tab
2. Click "Add Pipeline"
3. Name it "AprilTags"
4. Set pipeline type to "AprilTag"
5. Choose tag family: "k16h5" (most common)

**Tune settings**:
```
Exposure: 15
Brightness: 50
Gain: 30
```

### Step 4: Robot Code Integration

**Add PhotonVision**:

```java
// In build.gradle
dependencies {
    implementation "org.photonvision:photonlib:2024.+"
}

// In subsystem
private final PhotonCamera camera;

public VisionSubsystem() {
    camera = new PhotonCamera("YourCameraName");
}

public Optional<PhotonTrackedTarget> getBestTarget() {
    var result = camera.getLatestResult();
    if (result.hasTargets()) {
        return Optional.of(result.getBestTarget());
    }
    return Optional.empty();
}
```

### Step 5: Vision Odometry

**Add vision to pose estimation**:

```java
// In Drivetrain subsystem
private final PhotonPoseEstimator poseEstimator;

public Drivetrain() {
    // Create pose estimator
    poseEstimator = new PhotonPoseEstimator(
        AprilTagField.kDefaultField,
        PoseStrategy.CLOSEST_TO_CAMERA_POSE,
        camera,
        new Transform3d(0.5, 0, 0.5, new Rotation3d())  // Camera mount
    );
}

public void addVisionMeasurements() {
    vision.getBestTarget().ifPresent(target -> {
        poseEstimator.update();
        
        // Add vision measurement to odometry
        Optional<EstimatedRobotPose> estimatedPose = 
            poseEstimator.update();
            
        estimatedPose.ifPresent(pose -> {
            odometry.addVisionMeasurement(
                pose.estimatedPose.toPose2d(),
                pose.timestampSeconds
            );
        });
    });
}
```

## Quick Troubleshooting

**No targets detected**:
- Check camera exposure (lower it)
- Ensure adequate lighting
- Verify camera is connected
- Check network settings

**Targets flickering**:
- Increase exposure slightly
- Check for loose cables
- Verify power supply

**Robot code can't connect**:
- Ping camera: `ping 10.TE.AM.11`
- Check team number settings
- Verify Ethernet connection
- Restart robot code

**Vision odometry not working**:
- Verify camera-to-robot measurement
- Check field layout (AprilTag 7 is at origin)
- Add vision measurements periodically

## Camera Mounting Tips

**Ideal height**: 12-24 inches off ground
**Ideal angle**: 10-15 degrees upward
**Field of view**: 60-90 degrees recommended

**Camera placement**:
- **Front center**: Best for scoring targets
- **Back center**: Good for full-field awareness
- **High up**: Sees more of field
- **Low down**: Better for close-range shots

## Performance Tips

**Keep vision updates fast**:
```java
// Update vision at 50Hz (not faster!)
@Override
public void periodic() {
    double now = Timer.getFPGATimestamp();
    
    // Only update every 20ms
    if (now - lastUpdate > 0.02) {
        addVisionMeasurements();
        lastUpdate = now;
    }
}
```

**Optimize NetworkTables usage**:
```java
// Don't spam NetworkTables
private double lastPostedTX = 0;

if (Math.abs(tx - lastPostedTX) > 1.0) {
    SmartDashboard.putNumber("VisionTX", tx);
    lastPostedTX = tx;
}
```
