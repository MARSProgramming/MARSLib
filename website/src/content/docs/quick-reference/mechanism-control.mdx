# Mechanism Control Quick Reference

Control robot mechanisms like arms, elevators, and climbers. This guide has the essentials.

## Quick Setup (3 Steps)

### 1. Create Mechanism Subsystem

```java
public class ArmSubsystem extends Subsystem {
    private final LinearMechanism mechanism;
    
    public ArmSubsystem() {
        // Create mechanism with config and IO
        ArmConfig config = new ArmConfig();
        mechanism = new LinearMechanism(config, new ArmIOReal());
    }
    
    // Move to position
    public void setPosition(double meters) {
        mechanism.setPosition(meters);
    }
    
    // Get current position
    public double getPosition() {
        return mechanism.getPosition();
    }
}
```

### 2. Create Control Command

```java
public class MoveArmCommand extends Command {
    private final ArmSubsystem arm;
    private final double targetPosition;
    
    public MoveArmCommand(ArmSubsystem arm, double meters) {
        this.arm = arm;
        this.targetPosition = meters;
        addRequirements(arm);
    }
    
    @Override
    public void initialize() {
        arm.setPosition(targetPosition);
    }
    
    @Override
    public boolean isFinished() {
        return Math.abs(arm.getPosition() - targetPosition) < 0.05;  // 5cm tolerance
    }
}
```

### 3. Bind to Controller

```java
public class RobotContainer {
    private final ArmSubsystem arm = new ArmSubsystem();
    private final XboxController operator = new XboxController(1);
    
    public RobotContainer() {
        // Move arm to preset positions with buttons
        operator.a().onTrue(new MoveArmCommand(arm, 0.0));     // Stow
        operator.b().onTrue(new MoveArmCommand(arm, 0.5));     // Mid
        operator.y().onTrue(new MoveArmCommand(arm, 1.0));     // High
    }
}
```

## Common Mechanism Types

### Linear Mechanism (Elevator)

**Best for**: Moving things straight up/down

```java
public class ElevatorSubsystem extends Subsystem {
    private final LinearMechanism elevator;
    
    public ElevatorSubsystem() {
        ElevatorConfig config = new ElevatorConfig();
        config.maxHeight = 2.0;  // 2 meters
        config.minHeight = 0.0;
        
        elevator = new LinearMechanism(config, new ElevatorIOReal());
    }
    
    public void setHeight(double meters) {
        elevator.setPosition(meters);
    }
}
```

### Rotary Mechanism (Arm)

**Best for**: Rotating things (arms, turrets, intakes)

```java
public class TurretSubsystem extends Subsystem {
    private final RotaryMechanism turret;
    
    public TurretSubsystem() {
        TurretConfig config = new TurretConfig();
        config.maxAngle = Math.PI;  // 180 degrees
        config.minAngle = -Math.PI;
        
        turret = new RotaryMechanism(config, new TurretIOReal());
    }
    
    public void setAngle(double radians) {
        turret.setPosition(radians);
    }
}
```

### Flywheel (Shooter)

**Best for**: Spinning wheels to launch game pieces

```java
public class ShooterSubsystem extends Subsystem {
    private final Flywheel flywheel;
    
    public ShooterSubsystem() {
        ShooterConfig config = new ShooterConfig();
        config.maxVelocity = 20.0;  // m/s
        
        flywheel = new Flywheel(config, new ShooterIOReal());
    }
    
    public void setVelocity(double mps) {
        flywheel.setVelocity(mps);
    }
    
    public boolean atVelocity() {
        return Math.abs(flywheel.getVelocity() - flywheel.getTarget()) < 1.0;
    }
}
```

## Position Control

### Move to Specific Position

```java
// Simple position command
public class MoveToPosition extends Command {
    private final Mechanism mechanism;
    private final double target;
    
    public MoveToPosition(Mechanism mechanism, double targetPosition) {
        this.mechanism = mechanism;
        this.target = targetPosition;
        addRequirements(mechanism);
    }
    
    @Override
    public void initialize() {
        mechanism.setPosition(target);
    }
    
    @Override
    public boolean isFinished() {
        return mechanism.atTarget();
    }
}
```

### Velocity Control

```java
// Control mechanism speed (not position)
public class RunMechanism extends Command {
    private final Mechanism mechanism;
    private final double velocity;
    
    public RunMechanism(Mechanism mechanism, double velocity) {
        this.mechanism = mechanism;
        this.velocity = velocity;  // m/s or rad/s
        addRequirements(mechanism);
    }
    
    @Override
    public void execute() {
        mechanism.setVelocity(velocity);
    }
    
    @Override
    public void end(boolean interrupted) {
        mechanism.stop();
    }
}
```

## Feedforward Control

### What is Feedforward?

Feedforward predicts what output is needed instead of just reacting to error. It's like planning ahead instead of just correcting.

**When to use it**:
- ✅ **Gravity**: Arms and elevators (need power to hold position)
- ✅ **Friction**: Mechanisms with resistance
- ✅ **Velocity**: When controlling speed

### Add Gravity Feedforward

```java
public class ArmSubsystem extends Subsystem {
    private final LinearMechanism mechanism;
    private final SimpleMotorFeedforward feedforward;
    
    public ArmSubsystem() {
        ArmConfig config = new ArmConfig();
        mechanism = new LinearMechanism(config, new ArmIOReal());
        
        // Calculate feedforward gains (from SysId)
        double ks = 0.5;  // Static gain (overcome friction)
        double kg = 1.2;  // Gravity gain (hold against gravity)
        double kv = 2.0;  // Velocity gain
        double ka = 0.1;  // Acceleration gain
        
        feedforward = new SimpleMotorFeedforward(ks, kg, kv, ka);
    }
    
    @Override
    public void periodic() {
        // Calculate feedforward voltage
        double position = mechanism.getPosition();
        double velocity = mechanism.getVelocity();
        double ffVoltage = feedforward.calculate(velocity, 0);
        
        // Add gravity compensation
        ffVoltage += Math.cos(position) * feedforward.ks;
        
        // Apply feedforward + PID
        double pidOutput = mechanism.getController().calculate(position);
        mechanism.setVoltage(ffVoltage + pidOutput);
    }
}
```

## Safety Limits

### Prevent Over-Travel

```java
public class SafeMechism extends Subsystem {
    private final LinearMechanism mechanism;
    private final double MIN_POSITION = 0.0;
    private final double MAX_POSITION = 2.0;
    
    @Override
    public void periodic() {
        double position = mechanism.getPosition();
        
        // Emergency stop if out of bounds
        if (position < MIN_POSITION || position > MAX_POSITION) {
            mechanism.stop();
            DriverStation.reportError("Mechanism out of bounds!", false);
        }
    }
}
```

### Software Limits

```java
// In your config
public class ArmConfig {
    public double softLimitForward = 1.5;   // Stop before hitting physical limit
    public double softLimitReverse = 0.1;   // Stop before hitting physical limit
    
    public boolean enableSoftLimitForward = true;
    public boolean enableSoftLimitReverse = true;
}
```

## Homing

### What is Homing?

Homing finds the mechanism's starting position. Many mechanisms need to know where they are before they can move accurately.

### Simple Homing (Limit Switch)

```java
public class HomingCommand extends Command {
    private final Mechanism mechanism;
    private final DigitalInput limitSwitch;
    
    public HomingCommand(Mechanism mechanism, DigitalInput limitSwitch) {
        this.mechanism = mechanism;
        this.limitSwitch = limitSwitch;
        addRequirements(mechanism);
    }
    
    @Override
    public void execute() {
        // Move slowly toward home
        mechanism.setVelocity(-0.5);  // Move backward slowly
    }
    
    @Override
    public boolean isFinished() {
        // Stop when limit switch pressed
        return limitSwitch.get();
    }
    
    @Override
    public void end(boolean interrupted) {
        mechanism.stop();
        mechanism.setPosition(0.0);  // This is now home position
    }
}
```

### Absolute Encoder Homing

```java
// If using absolute encoder (like CANcoder)
public class AbsoluteHomingCommand extends Command {
    private final Mechanism mechanism;
    private final CANcoder absoluteEncoder;
    
    public AbsoluteHomingCommand(Mechanism mechanism, CANcoder absoluteEncoder) {
        this.mechanism = mechanism;
        this.absoluteEncoder = absoluteEncoder;
        addRequirements(mechanism);
    }
    
    @Override
    public void initialize() {
        // Read absolute encoder position
        double absolutePosition = absoluteEncoder.getAbsolutePosition();
        
        // Set mechanism position to match
        mechanism.setPosition(absolutePosition);
    }
    
    @Override
    public boolean isFinished() {
        return true;  // Done immediately
    }
}
```

### Manual Control

```java
// Control mechanism with joystick
public class ManualArmCommand extends Command {
    private final ArmSubsystem arm;
    private final XboxController operator;
    
    public ManualArmCommand(ArmSubsystem arm, XboxController operator) {
        this.arm = arm;
        this.operator = operator;
        addRequirements(arm);
    }
    
    @Override
    public void execute() {
        // Use joystick to control arm position
        double joystick = operator.getLeftY();  // -1 to 1
        
        // Convert joystick to arm speed
        double speed = joystick * 0.5;  // Max 0.5 m/s
        
        arm.setVelocity(speed);
    }
    
    @Override
    public void end(boolean interrupted) {
        arm.holdPosition();  // Hold last position when released
    }
}
```

### Integrate with Vision

```java
// Aim mechanism using vision
public class VisionAimCommand extends Command {
    private final TurretSubsystem turret;
    private final VisionSubsystem vision;
    private final PIDController controller;
    
    public VisionAimCommand(TurretSubsystem turret, VisionSubsystem vision) {
        this.turret = turret;
        this.vision = vision;
        this.controller = new PIDController(2.0, 0, 0.1);
        addRequirements(turret);
    }
    
    @Override
    public void execute() {
        // Get target yaw from vision
        Optional<Double> targetYaw = vision.getTargetYaw();
        
        if (targetYaw.isPresent()) {
            // Calculate turret angle adjustment
            double output = controller.calculate(targetYaw.get(), 0.0);
            
            // Move turret
            double currentAngle = turret.getAngle();
            turret.setAngle(currentAngle + output);
        }
    }
    
    @Override
    public boolean isFinished() {
        // Finished when aimed at target
        return vision.getTargetYaw()
            .map(yaw -> Math.abs(yaw) < 0.05)  // Within ~3 degrees
            .orElse(false);
    }
}
```

## Troubleshooting

### Problem: Mechanism Won't Move

**Check**:
```java
// 1. Is mechanism being commanded?
System.out.println("Target: " + mechanism.getTarget());
System.out.println("Current: " + mechanism.getPosition());

// 2. Is motor getting power?
System.out.println("Motor output: " + mechanism.getMotorOutput());

// 3. Any faults?
System.out.println("Faults: " + mechanism.getFaults());
```

### Problem: Mechanism Oscillates

**Fix**:
```java
// 1. Reduce PID gains
controller.setP(controller.getP() / 2);

// 2. Add D term
controller.setD(0.1);

// 3. Check feedforward is correct
// Make sure it's not fighting PID
```

### Problem: Can't Reach Position

**Check**:
- Physical limits (mechanism hitting something)
- Soft limits configured incorrectly
- Motor not powerful enough
- Mechanism binding/stuck

## Quick Tips

### While Tuning:
- ✅ **Start slow** - Low gains first
- ✅ **Test in simulation** - Save time
- ✅ **Use SysId** - Identify gains automatically
- ✅ **Document settings** - Write down what works

### Safety:
- ⚠️ **Always test without game pieces first**
- ⚠️ **Have e-stop ready**
- ⚠️ **Check physical limits in software**
- ⚠️ **Test slow motion before fast**

### Performance:
- ✅ **Use feedforward** - Improves response
- ✅ **Tune PID** - Better accuracy
- ✅ **Limit velocity** - Smoother motion
- ✅ **Add safety limits** - Prevent damage
