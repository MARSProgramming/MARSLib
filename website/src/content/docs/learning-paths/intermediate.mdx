# Intermediate Learning Path (Weeks 3-4)

Ready to level up your robotics skills? This path builds on the beginner course to teach you advanced features like vision systems, complex autonomous routines, and competition-winning strategies.

## What You'll Learn

By the end of this 4-week program, you'll master:
- **Vision Systems**: AprilTag tracking and object detection
- **Advanced Autonomous**: Path following and multi-piece autos
- **Performance Tuning**: Make your robot faster and more accurate
- **Competition Prep**: Strategy, debugging, and reliability

**Prerequisites**: Complete [Beginner Learning Path](/learning-paths/beginner) or equivalent experience

---

## Week 3: Vision Systems

### Day 15-16: Vision Basics

**✅ Goals**:
- Understand how robot vision works
- Set up vision cameras (Limelight/PhotonVision)
- Detect AprilTags and game pieces
- Use vision data in robot code

**📚 Read**:
- [Vision Systems Overview](/tutorials/vision/intro)
- [AprilTag Tracking](/tutorials/vision/apriltags)
- [PhotonVision Setup](/tutorials/vision/photonvision)

**🎯 Activities**:
1. Set up vision camera (Limelight or PhotonVision)
2. Detect AprilTags in simulation
3. Read vision data in robot code
4. Display vision targets on dashboard

**⏱️ Time**: 3-4 hours


**Option C: Multi-Camera System**

```
- Automatic camera switching

- Competition-ready vision system
```

## Tips for Success

### 🎯 Set Weekly Goals
Each week, pick 2-3 goals to accomplish. Don't try to do everything!

### 🧪 Test Everything
Use simulation extensively before testing on real robot.

### ❓ Ask Questions
Don't struggle alone! The community is here to help.

### 📝 Document Your Work
Write down what you learn. Future you will thank present you!

### 🎉 Celebrate Progress
Did something work? That's awesome! Celebrate your progress!

## Troubleshooting

### "I'm Stuck!"
1. Review the beginner material
2. Check troubleshooting guides
3. Search GitHub Issues
4. Ask in Discussions

### "This is Too Hard!"
1. Take a break and come back later
2. Try a simpler example
3. Ask a teammate for help
4. Remember: you've got this!

### "I Don't Understand!"
1. Read it out loud
2. Draw a picture
3. Find a different explanation
4. Ask someone to explain it differently
