# Beginner Learning Path (Weeks 1-2)

Welcome to your robotics journey! This path takes you from zero experience to driving a robot in just 2 weeks.

## Week 1: Foundation

### Day 1-2: Setup and Basics

**✅ Goals:**
- Set up your development environment
- Understand what robot code looks like
- Write your first robot program

**📚 Read:**
- [Getting Started with MARSLib](/beginner/getting-started)
- [What is a Subsystem?](/tutorials/framework/subsystems)

**🎯 Activities:**
1. Install Java 17 and VS Code
2. Clone MARSLib to your computer
3. Create a new robot project
4. Run your first simulation

**⏱️ Time:** 2-3 hours

---

### Day 3-4: Subsystems and Hardware

**✅ Goals:**
- Understand what subsystems are
- Learn about the IO Abstraction Layer
- Create your first subsystem

**📚 Read:**
- [IO Abstraction Explained](/tutorials/framework/io-abstraction)
- [Hardware Connection Guide](/tutorials/hardware/connecting-devices)

**🎯 Activities:**
1. Create a `Drivetrain` subsystem
2. Add simulated IO to test without robot
3. Run simulation and see your drivetrain work!

**⏱️ Time:** 2-3 hours

---

### Day 5-6: Commands and Control

**✅ Goals:**
- Understand command-based programming
- Write your first command
- Connect controller to robot

**📚 Read:**
- [Commands Explained](/tutorials/framework/commands)
- [Controller Input Guide](/tutorials/hardware/controllers)

**🎯 Activities:**
1. Create a `DriveCommand` that uses joystick input
2. Set up XboxController in code
3. Make robot drive in simulation!

**💡 Victory Moment:** Your simulated robot drives when you press keys!

**⏱️ Time:** 3-4 hours

---

### Day 7: Integration and Testing

**✅ Goals:**
- Put everything together
- Test your robot code
- Practice debugging

**📚 Read:**
- [Robot Container Guide](/tutorials/framework/robot-container)
- [Debugging Tips](/operations/debugging)

**🎯 Activities:**
1. Create RobotContainer to tie parts together
2. Test in simulation thoroughly
3. Practice finding and fixing bugs

**🏆 Week 1 Complete!** You have a working robot program!

**⏱️ Time:** 2-3 hours

---

## Week 2: Skills

### Day 8-9: Advanced Driving

**✅ Goals:**
- Learn field-relative driving
- Understand odometry
- Drive to specific positions

**📚 Read:**
- [Odometry Explained](/tutorials/framework/odometry)
- [Field-Relative Driving](/tutorials/advanced/field-relative)

**🎯 Activities:**
1. Implement field-relative drive
2. Add odometry display
3. Drive to specific field positions

**⏱️ Time:** 3-4 hours

---

### Day 10-11: Adding Mechanisms

**✅ Goals:**
- Create mechanism subsystems
- Control mechanisms with commands
- Learn PID basics

**📚 Read:**
- [Mechanism Guide](/tutorials/framework/mechanisms)
- [PID Controllers](/tutorials/control-theory/pid-intro)

**🎯 Activities:**
1. Create a simple mechanism (like an arm)
2. Add PID control
3. Test mechanism movement

**⏱️ Time:** 3-4 hours

---

### Day 12-13: Autonomous Basics

**✅ Goals:**
- Understand autonomous programming
- Write a simple auto routine
- Test autonomous in simulation

**📚 Read:**
- [Autonomous Guide](/tutorials/autonomous/intro)
- [Path Following Basics](/tutorials/advanced/path-following)

**🎯 Activities:**
1. Create a simple auto command
2. Make robot drive in a square
3. Test and tune autonomous

**💡 Victory Moment:** Your robot drives itself!

**⏱️ Time:** 3-4 hours

---

### Day 14: Final Project

**✅ Goals:**
- Put all skills together
- Build something cool
- Celebrate your progress!

**🎯 Project Options:**

**Option A: Obstacle Course**
```
- Drive around obstacles
- Use field-relative driving
- End at specific position
- Add autonomous mode
```

**Option B: Mechanism Game**
```
- Move mechanism to target positions
- Use controller buttons
- Add automatic sequences
- Create scoring system
```

**Option C: Auto Navigation**
```
- Plan path through field
- Follow path accurately
- Adjust for obstacles
- Time and optimize
```

**🏆 Week 2 Complete!** You're now a robot programmer!

**⏱️ Time:** 4-6 hours

## Tips for Success

### 🎯 Set Goals
Each day, pick 1-2 goals to accomplish. Don't try to do everything!

### 🧪 Test Often
Run simulation frequently to catch mistakes early.

### ❓ Ask Questions
Don't struggle alone! The community is here to help.

### 📝 Take Notes
Write down what you learn. Future you will thank present you!

### 🎉 Celebrate Wins
Did something work? That's awesome! Celebrate your progress!

### 🔄 Repeat if Needed
It's okay to spend extra time on tough concepts. Learning takes time!

## Troubleshooting

### "I'm Stuck!"
1. Read the documentation again
2. Check the FAQ
3. Search GitHub Issues
4. Ask in Discussions

### "This is Too Hard!"
1. Take a break and come back later
2. Try a simpler example
3. Ask a teammate for help
4. Remember: everyone starts somewhere!

### "I Don't Understand!"
1. Read it out loud
2. Draw a picture
3. Find a different explanation
4. Ask someone to explain it differently
