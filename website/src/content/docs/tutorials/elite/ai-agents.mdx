# AI Integration in MARSLib

At MARS 2614, we don't just write code; we teach AI how to write code for us. MARSLib is fundamentally co-developed with Artificial Intelligence models (such as Claude/Z.ai), which act as active participants in scaffolding subsystems, auditing physics compliance, and enforcing architectural standards via our local `.agents/skills/` directory.

When using an AI-agent within the MARSLib workspace, you can explicitly ask the agent to invoke specific "skills" by name to govern its execution boundaries. 

Beyond code generation, our AI is fundamentally designed to act as a **Socratic educational mentor** (via the `marslib-tutor` skill). We strongly believe in utilizing AI as a dedicated tutor to ensure students deeply learn the complex robotics engineering and physics principles underlying the framework, rather than just copying syntax.

---

## Core Framework Skills

| Agent Skill Name | Purpose & Workflow |
|---|---|
| **`marslib`** | The general-purpose framework architect. Use when adding new sub-systems or managing generic IO patterns. |
| **`marslib-core-standards`** | Enforces the "Never Nester" rule, explicit mathematical documentation, and strict structural aesthetics on modified classes. |
| **`marslib-audit`** | Executes a championship-grade code audit across the repository to enforce maximum reliability. |
| **`marslib-skill-authoring`** | Helps author and serialize brand new `.agent` skills to scale the framework's intelligence. |
| **`marslib-tutor`** | Overrides standard productivity directives to become a patient, Socratic mentor. Prioritizes teaching the "Why" underlying FRC physics and architecture over just dumping code. |

### Agentic Enforcement Tag

Whenever an AI algorithm is tasked to structure a specific code loop (like the SOTM targeting loop or logging arrays), use the `@AGENT_ENFORCED` block tag right inside your code editor to explicitly warn human developers from accidentally refactoring crucial, mechanically generated syntax patterns.
