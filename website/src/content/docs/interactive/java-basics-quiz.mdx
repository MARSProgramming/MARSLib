## Question 11: Null

**What happens with this code?**

```java
String name = null;
System.out.println(name.length());
```

<details>
<summary>Show Answer</summary>

**Answer: NullPointerException (crashes!)**

**Why?**
- `name` is `null` (nothing)
- Can't call methods on nothing
- Java throws an error

**How to fix**:
```java
String name = null;
if (name != null) {
    System.out.println(name.length());
}
```

**Think of it like**:
- Trying to open a door that doesn't exist
- You can't do it!
- Check if the door exists first
</details>

## Question 14: Equality

**What does this code print?**

```java
String a = new String("hello");
String b = new String("hello");
if (a == b) {
    System.out.println("Same");
} else {
    System.out.println("Different");
}
```

<details>
<summary>Show Answer</summary>

**Answer: Different**

**Why?**
- `==` checks if they're the SAME object
- `.equals()` checks if they have the SAME VALUE
- `a` and `b` are different objects with same value

**How to fix**:
```java
if (a.equals(b)) {
    System.out.println("Same");  // This prints!
}
```

**Think of it like**:
- Two different cookies
- Both are chocolate chip
- They're not the SAME cookie
- But they're the same TYPE of cookie
</details>

## Question 15: Scope

**What does this code print?**

```java
int x = 5;
if (true) {
    int x = 10;  // Line A
    System.out.println(x);  // Line B
}
System.out.println(x);  // Line C
```

<details>
<summary>Show Answer</summary>

**Answer: This code doesn't compile!**

**Why?**
- Can't declare `x` twice in the same scope
- The outer `x` is still visible inside the if
- Java doesn't know which `x` you mean

**Fix**:
```java
int x = 5;
if (true) {
    x = 10;  // Just assign, don't redeclare
}
System.out.println(x);  // Prints 10
```

**Think of it like**:
- You can't have two people with the same name in the same room
- But you can have different people with same name in different rooms
</details>
