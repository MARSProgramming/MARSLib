## Core Packages

### [`com.marslib.swerve`](pathname:///javadoc/com/marslib/swerve/package-summary.html)
**Swerve Drive & Odometry**

High-performance swerve drive implementation with 250Hz odometry updates, traction control, and path following integration.

**Key Classes:**
- [`SwerveDrive`](pathname:///javadoc/com/marslib/swerve/SwerveDrive.html) - Main swerve drive subsystem
- [`SwerveModule`](pathname:///javadoc/com/marslib/swerve/SwerveModule.html) - Individual swerve module
- [`PhoenixOdometryThread`](pathname:///javadoc/com/marslib/swerve/PhoenixOdometryThread.html) - High-frequency odometry thread
- [`SwerveConfig`](pathname:///javadoc/com/marslib/swerve/SwerveConfig.html) - Configuration parameters

**Common Usage:**
```java
// Create swerve drive
SwerveDrive drive = new SwerveDrive(new SwerveModuleIOSim(), config);

// Drive with velocities
var speeds = new ChassisSpeeds(vx, vy, omega);
drive.driveRobotRelative(speeds);

// Get odometry pose
Pose2d pose = drive.getPose();
```

### [`com.marslib.vision`](pathname:///javadoc/com/marslib/vision/package-summary.html)
**Vision & Localization**

AprilTag detection and MegaTag 2.0 SLAM fusion for accurate robot localization.

**Key Classes:**
- [`MARSVision`](pathname:///javadoc/com/marslib/vision/MARSVision.html) - Main vision system
- [`VisionIO`](pathname:///javadoc/com/marslib/vision/VisionIO.html) - Vision hardware interface
- [`VisionConfig`](pathname:///javadoc/com/marslib/vision/VisionConfig.html) - Vision configuration
- [`AprilTagVisionIO`](pathname:///javadoc/com/marslib/vision/AprilTagVisionIO.html) - AprilTag camera interface

**Common Usage:**
```java
// Create vision system
MARSVision vision = new MARSVision(new AprilTagVisionIOReal(camera), config);

// Get fused pose estimate
Optional<Pose2d> pose = vision.getPoseEstimate();

// Add vision measurement to odometry
drive.addVisionMeasurement(pose.get(), timestamp);
```

### [`com.marslib.mechanisms`](pathname:///javadoc/com/marslib/mechanisms/package-summary.html)
**Generic Mechanisms**

Reusable abstractions for common robot mechanisms.

**Key Classes:**
- [`RotaryMechanismIO`](pathname:///javadoc/com/marslib/mechanisms/RotaryMechanismIO.html) - Rotary mechanism interface
- [`LinearMechanismIO`](pathname:///javadoc/com/marslib/mechanisms/LinearMechanismIO.html) - Linear mechanism interface
- [`FlywheelIO`](pathname:///javadoc/com/marslib/mechanisms/FlywheelIO.html) - Flywheel interface

**Common Usage:**
```java
// Create rotary mechanism (shooter, arm)
RotaryMechanismIO shooter = new RotaryMechanismIOReal(motor);

// Create linear mechanism (elevator)
LinearMechanismIO elevator = new LinearMechanismIOReal(motor);
```

## Hardware Abstraction

### [`com.marslib.power`](pathname:///javadoc/com/marslib/power/package-summary.html)
**Power Management**

Voltage load-shedding and stator current monitoring to prevent brownouts.

**Key Classes:**
- [`MARSPowerManager`](pathname:///javadoc/com/marslib/power/MARSPowerManager.html) - Power monitoring and load shedding
- [`PowerConfig`](pathname:///javadoc/com/marslib/power/PowerConfig.html) - Voltage thresholds

**Common Usage:**
```java
// Create power manager
MARSPowerManager power = new MARSPowerManager(pdh, config);

// Check voltage status
boolean lowVoltage = power.isLowVoltage();
boolean critical = power.isCriticalVoltage();
```

### [`com.marslib.faults`](pathname:///javadoc/com/marslib/faults/package-summary.html)
**Fault Management**

Thread-safe fault reporting and alert system for robot health monitoring.

**Key Classes:**
- [`MARSFaultManager`](pathname:///javadoc/com/marslib/faults/MARSFaultManager.html) - Central fault manager
- [`Alert`](pathname:///javadoc/com/marslib/faults/Alert.html) - Fault alerts

**Common Usage:**
```java
// Report fault
MARSFaultManager.fault("Shooter wheel timeout!");
MARSFaultManager.warn("Vision high ambiguity");

// Check for faults
boolean hasFaults = MARSFaultManager.hasAnyFault();
```

## Simulation

### [`com.marslib.simulation`](pathname:///javadoc/com/marslib/simulation/package-summary.html)
**Physics Simulation**

High-fidelity physics simulation using Dyn4j for realistic robot behavior.

**Key Classes:**
- [`MARSPhysicsWorld`](pathname:///javadoc/com/marslib/simulation/MARSPhysicsWorld.html) - Physics world manager
- [`GamePieceBody`](pathname:///javadoc/com/marslib/simulation/GamePieceBody.html) - Game piece physics

**Common Usage:**
```java
// Get physics world instance
MARSPhysicsWorld world = MARSPhysicsWorld.getInstance();

// Update physics (called in test loop)
world.update(0.02); // 20ms timestep

// Spawn game pieces
world.spawnGamePiece(x, y);
```

### Usage Pattern
```java
// Define interface
public interface MechanismIO {
    double getPosition();
    void setVoltage(double volts);
}

// Hardware implementation
public class MechanismIOReal implements MechanismIO {
    private final TalonFX motor;
    
    public double getPosition() {
        return motor.getPosition().getValueAsDouble();
    }
    
    public void setVoltage(double volts) {
        motor.setVoltage(volts);
    }
}

// Simulated implementation
public class MechanismIOSim implements MechanismIO {
    private double position = 0.0;
    
    public double getPosition() {
        return position;
    }
    
    public void setVoltage(double volts) {
        // Physics simulation
        position += volts * 0.02; // Simplified
    }
}

// Subsystem works with any implementation
public class MechanismSubsystem extends Subsystem {
    private final MechanismIO io;
    
    public MechanismSubsystem(MechanismIO io) {
        this.io = io;
    }
    
    @Override
    public void periodic() {
        // Works the same on robot and in simulation!
        double pos = io.getPosition();
    }
}
```

## Quick Reference

### Common Tasks

**Create a swerve drive command:**
```java
public class DriveCommand extends Command {
    private final SwerveDrive drive;
    private final Supplier<Double> vx, vy, omega;
    
    public DriveCommand(SwerveDrive drive, 
                       Supplier<Double> vx, 
                       Supplier<Double> vy, 
                       Supplier<Double> omega) {
        this.drive = drive;
        this.vx = vx;
        this.vy = vy;
        this.omega = omega;
        addRequirements(drive);
    }
    
    @Override
    public void execute() {
        var speeds = new ChassisSpeeds(vx.get(), vy.get(), omega.get());
        drive.driveRobotRelative(speeds);
    }
}
```

**Use vision for alignment:**
```java
public class AlignCommand extends Command {
    private final MARSVision vision;
    private final SwerveDrive drive;

    public void execute() {
        var pose = vision.getPoseEstimate();
        if (pose.isPresent()) {
            // Calculate alignment
            // Drive to target
        }
    }
}
```

```java
public enum State { IDLE, INTAKING, SHOOTING }

MARSStateMachine<State> sm = new MARSStateMachine<>("Robot", State.IDLE);
sm.addState(State.IDLE, () -> { /* idle behavior */ });
sm.addState(State.INTAKING, () -> { /* intaking behavior */ });
```
