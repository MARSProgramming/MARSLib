# Tech Stack

## Core Technologies
- **Language**: Java
- **Build System**: Gradle
- **Framework**: WPILib (FIRST Robotics Competition standard library)
- **Logging/Telemetry**: AdvantageKit (Mechanical Advantage)
- **Physics Engine**: Dyn4j (2D Collision/Simulation)
- **Pathing/Trajectories**: PathPlanner

## Dependencies
- CTRE Phoenix 6 (TalonFX, CANcoder, Pigeon2)
- REV Robotics (SparkMax, SparkFlex)
- PhotonVision (Vision Processing)

## CI/CD
- GitHub Actions (Linting, Testing, Build)
- Spotless (Code Formatting)
